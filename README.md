# Lë Super Republic — Drop III

Independent streetwear clothing house from Ga-Rankuwa, Gauteng, South Africa.

## Live Website

Once GitHub Pages is enabled, the store will be available at:

**https://reaankysa-maker.github.io/lesuper-republic/**

## How to enable GitHub Pages

1. Go to the repository: https://github.com/reaankysa-maker/lesuper-republic
2. Click **Settings** → **Pages** (left sidebar)
3. Under **Source**, select **Deploy from a branch**
4. Choose branch **main** and folder **/ (root)**
5. Click **Save**

The site will be live in 1–2 minutes.

## Important: Full website file

The current `index.html` in the repo is incomplete (size limits when uploading automatically).

**To publish the complete website with all product images and full functionality:**

1. Take your full `lesuper-republic-store.html` file
2. Rename it to `index.html`
3. Upload / replace it on GitHub:
   - Open https://github.com/reaankysa-maker/lesuper-republic
   - Click on `index.html`
   - Click the pencil (Edit this file) or use the Upload files button
   - Paste or drag the full content / file
   - Commit the changes

Or from your computer with git:
```bash
git clone https://github.com/reaankysa-maker/lesuper-republic.git
cd lesuper-republic
# copy your full HTML over index.html
git add index.html
git commit -m "Add complete Drop III store"
git push
```
